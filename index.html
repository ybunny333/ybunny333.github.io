System Architecture & Security Concept

Traditional text passwords are overwhelmingly vulnerable to dictionary attacks, keyloggers, shoulder surfing, and credential stuffing. The Graphical Password Authentication System introduces a spatial-visual verification protocol where the user selects predefined points on a designated graphic canvas.

Security Implementations:
  • Coordinate Tolerance Jitter: Applies Euclidean distance bounds around click coordinates so minor user drift is tolerated without exposing precision vulnerabilities.
  • Salting & SHA-256: Click sequence data is combined with a cryptographically secure salt before hashing, preventing offline rainbow table reconstruction.
  • Lockout Mechanism: Implements exponential backoff delays following 3 consecutive failed login attempts to neutralize brute-force automation.
